# Консоль параметрлері

`self` параметрін бермеңіз. Қалғандары key=value форматында енгізіледі.

- `add(self, sku, name, category)`
- `get(self, sku)`
- `update(self, sku, name, category)`
- `delete(self, sku)`
- `move(self, sku, kind, quantity)`
- `search(self, query='', category=None)`
- `report(self)`
- `journal(self)`
