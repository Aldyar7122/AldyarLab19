# Конфигурацияны басқару жоспары

## 1 Қолдану саласы
Оқу жобасының бастапқы коды, тесттері, конфигурациясы және шығарылымдары бақыланады.
ISO/IEC/IEEE 828:2012 қағидаттары оқу негізі ретінде қолданылады; толық сәйкестік не сертификаттау мәлімделмейді.

## 2 Рөлдер
Developer өзгерісті іске асырады. Reviewer сұраудың себебі мен тестін тексереді.
Configuration Manager baseline мен шығарылымды тіркейді. Бір студент осы оқу рөлдерін кезекпен атқарады.
Қосымшада толық аутентификация және рөлдерді тәуелсіз бөлу жоқ.

## 3 Сәйкестендіру
CI ID, салыстырмалы жол, нұсқа және SHA-256 тіркеледі. Git коммиті толық hash арқылы көрсетіледі.
src, tests, pyproject.toml, workflow және құжаттар конфигурациялық бірліктерге жатады.

## 4 Өзгерісті келісу
CR тіркеу → әсерді бағалау → approve немесе reject → feature тармағы → тест → merge.
Мақұлданбаған сұрауды apply арқылы қолдануға болмайды. Git hash пен тест идентификаторы сұрауға қосылады.
Қарау нәтижесі, шешім себебі және мақұлдаушының аты сақталады.

## 5 Baseline
Baseline бірегей ID, күн, мақұлдаушы және бірліктер тізімін қамтиды.
Бекітілген жазба өзгертілмейді. Келесі күй жаңа ID және previous сілтемесі арқылы тіркеледі.
Файлдық snapshot .scm ішінде сақталады; каталог сканерлеуден шығарылады.
SQLite baseline UPDATE және DELETE әрекеттері триггермен тоқтатылады.

## 6 Мәртебелерді есепке алу
CHANGELOG, сұраулар журналы, item_versions және history оқиғалары сақталады.
Есепте CR → шешім → commit → baseline → test байланысы көрсетіледі.

## 7 Аудит
pytest функцияларды, ruff кодты, аудитор ішкі ережелерді тексереді.
SHA-256 тексеруі файлдың baseline-ға қатысты өзгергенін көрсетеді.
Аудитор GitHub CI нәтижесінің шынайылығын немесе толық стандарт сәйкестігін өздігінен растамайды.

## 8 Шығарылым
Барлық тест пен аудит өткен соң версия, baseline және Git tag тіркеледі.
Тег пакет нұсқасына сәйкес болғанда wheel және sdist жасалады.
Artifacts сақталады; өндірістік ортаға deployment осы жұмыстың ауқымына кірмейді.
Тікелей DB әкімшісі немесе файлға сырттан қолжетімділік үшін криптографиялық қолтаңба қорғанысы жоқ.
