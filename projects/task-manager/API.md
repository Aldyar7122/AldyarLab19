# Консоль параметрлері

`self` параметрін бермеңіз. Қалғандары key=value форматында енгізіледі.

- `add(self, title, assignee, priority='normal', status='planned')`
- `get(self, id)`
- `update(self, id, title=None, assignee=None, priority=None, status=None)`
- `delete(self, id)`
- `list(self, assignee=None, priority=None, status=None)`
- `statistics(self)`
