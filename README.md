# 19–20 практикалық жұмыс

9 жеке Python жобасы `projects/` ішінде. Әр жобада README, API, тесттер, SCM жоспары және нақты дәлелдер бар.
Python 3.11 және 3.12 қолданылады. `pip install -r requirements-dev.txt`, содан кейін `python scripts/check_all.py`.
Жеке жобада `python demo.py` көрсетілімді қайталайды. Орнату нұсқаулығы жоба README ішінде.
Бастапқы жеке Git тарихы `evidence/histories/` бумасындағы Git bundle файлдарында сақталған.
`git clone evidence/histories/NAME.bundle NAME` арқылы барлық тармақты қалпына келтіруге болады.
Тармақтар тізімін тексеру үшін `git branch -a`, тегтер үшін `git tag -n` қолданыңыз.

Оқу жобасы ISO/IEC/IEEE 828:2012 қағидаттарына сүйенеді; толық сәйкестік немесе сертификаттау мәлімдемейді.
Есептегі commit hash пен CI URL нақты репозиторий тарихымен тексеріледі.
